# ViteYutnori

Vite + React + 상태 관리 라이브러리(Jotai 또는 Zustand)로 만든 윷놀이 게임. (현재 앱 제작 중)

## 목적

- 윷놀이 실물을 들고 다닐 수가 없어 태블릿이나 PC를 통해 가족이나 친구끼리 할 수 있는 윷놀이 게임을 만들어보고자 함.
- 넷마블 윷놀이의 경우 확률적으로 "낙"이 발생할 수 있어, 불쾌감의 가능성이 있음.
- 그래서 "낙"이 없으며, 웹 브라우저를 가지고 있으면 실물이 없어도 즐길 수 있는 게임을 만들고 싶음.

## 게임 규칙

- 플레이 인원 수를 정한다. (2~4명)
- 플레이 인원 수가 정해지면 인원 수에 맞게 게임을 초기화한다.
- 3개의 일반 윷가락, 1개의 특수 윷가락, 총 4개의 윷가락을 던진다.
  - 도: 1개의 일반 윷가락만 펴져 있고, 나머지 세 윷가락은 엎어져 있을 때.
  - 개: 두 윷가락(일반/특수 무관)이 펴져 있을 때.
  - 걸: 세 윷가락(일반/특수 무관)이 펴져 있을 때.
  - 윷: 네 윷가락이 모두 펴져 있을 때.
    - 윷가락을 한 번 더 던질 수 있다.
  - 모: 네 윷가락이 모두 엎어져 있을 때.
    - 윷가락을 한 번 더 던질 수 있다.
  - 빽도: 1개의 특수 윷가락만 펴져 있고, 나머지 세 윷가락은 엎어져 있을 때.
    - 윷판에 놓여진 자기 말이 없으면 턴을 스킵한다.
- 이번 턴에서 더 이상 윷가락을 던질 수 없게 됐을 때, 윷가락을 던진 결과마다 움직일 말을 골라 이동시킨다.
  - 대기실에 있는 말을 이동시킬 때, 0번부터 첫번째 칸으로 시작하여 이동한다.
    - 예 1: 도로 대기실에 있는 말을 이동시킬 때 그 말을 0번째 칸에 멈춘다.
    - 예 2: 걸로 대기실에 있는 말을 이동시킬 때 그 말을 2번째 칸에 멈춘다.
  - 이미 윷판에 놓여진 말을 이동시킬 경우, `board-moves.png`의 표를 참고.
  - 참고로, 초기에 대기실에는 각 플레이어마다 4개의 말이 있다.
- 업기
  - 동일한 플레이어의 말과 같은 곳에 멈췄을 경우, 말을 포갠다.
    - 동일한 플레이어의 말을 지나쳤을 경우 포개지 않는다.
  - 포갠 말은 다른 플레이어의 말에 잡히거나 골인할 때까지 한 몸으로 움직이게 된다.
- 잡기
  - 다른 플레이어의 말과 같은 곳에 멈췄을 경우, 말을 잡아 대기실로 돌려보낸다.
    - 다른 플레이어의 말을 지나쳤을 경우 잡지 않는다.
    - 잡아놓은 다른 플레이어의 말이 포갠 상태였다면, 포갠 수만큼 대기실로 돌려보낸다. 또한, 대기실로 돌려보내진 말은 다시 따로따로 출발해야 한다.
  - 다른 플레이어의 말을 잡을 때마다, 윷가락을 던질 기회가 한 번 더 주어진다.
- 승리
  - 4개의 말을 모두 골인시키는 플레이어가 승리한다.

## 태스크 브레이크다운

- 윷놀이 앱 구현
  - UI 정의
    - 타이틀 정의
    - 버튼 정의
      - 일반 버튼 정의
        - 초록색 버튼
      - 취소 버튼 정의
        - 빨강색 버튼
    - 모달 대화상자 정의
      - 모달 대화상자 정의
      - 모달용 타이틀 정의
      - 닫기 버튼 정의
  - 게임 요소 정의
    - 보드 정의
      - 칸 정의
        - 공통 칸 정의
          - 하얀 원
        - 꼭짓점과 중앙에 해당하는 칸 정의
          - 플레이 영역의 10% 크기
        - 나머지 칸에 대한 정의
          - 플레이 영역의 6% 크기
      - 칸 연결선 표현 정의
        - 칸 연결선을 먼저 그리고 그 위에 칸을 그려넣는 방식으로 렌더링하기
        - 플레이 영역의 80% 크기
      - 말이 움직일 수 있는 칸 표현 정의
        - 하얀 원을 노란색으로 임시로 변경 표시
    - 플레이어 말 정의
      - 말 표현 정의
        - 공통 말 표현 정의
          - 플레이 영역의 12% 크기
          - 말이 여러 마리일 경우 그 수 만큼 오른쪽 아래 첨자에 숫자로 표시
        - 1P 말 표현 정의
          - 원 모양
          - 빨강색
        - 2P 말 표현 정의
          - 세모 모양
          - 파랑색
        - 3P 말 표현 정의
          - 네모 모양
          - 초록색
        - 4P 말 표현 정의
          - 별 모양
          - 보라색
      - 말의 움직임 정의
        - 말의 움직임 행동 정의
          - 일반 이동 정의
          - 골인 정의
          - 동일 플레이어의 말과 겹침 정의
          - 다른 플레이어의 말을 잡음 정의
        - 말의 움직임 표현 정의
          - 칸에서 칸으로 움직이는 표현 정의
          - 골인 표현 정의
    - 말 대기실 정의
      - 대기하는 말 정의
      - 말의 출발 정의
    - 윷가락 정의
      - 윷가락 타입 정의 (`Yut` 타입)
        - 뒤집어져 있는지 여부 정의: `isFlipped`
          - 윷가락이 펴져 있는 경우 `false`
        - 빽도를 결정하는 특수 윷가락 정의: `isMarked`
      - 윷 던지기 정의
        - 윷 던지기 행동 정의
          - 4개의 윷가락에 대해 각 `isFlipped`를 랜덤으로 결정
          - 그 다음 4개의 윷가락 중 하나를 랜덤으로 골라 `isMarked`를 `true`로 설정
        - 윷 던지기 표현 정의
    - 윷 던지기 결과 정의 -> 게임 규칙 참조
  - 상태 정의
    - 게임 상태 정의
      - 플레이하는 인원 수 정의: `numberOfPlayers` (정수 타입)
        - 2~4명
      - 지금 어느 플레이어 턴인지 정의: `currentPlayer` (정수 타입)
        - `1` 이상 `numberOfPlayers` 이하
      - 해당 턴의 플레이어가 몇 번 윷을 던질 수 있는지 정의: `throwChances` (정수 타입)
      - 최근 윷 던지기 결과 정의: `recentThrowResult` (`ThrowResult` 타입)
      - 사용할 수 있는 윷 던지기 결과 모음 정의: `throwResults` (`{ ThrowResult: 정수 }` 타입)
        - 선택한 말(`selectedPawnAt`)이 있을 경우 그 말이 어느 칸으로 갈 수 있을지 정의: `possibleRoutes`
      - 보드 칸별 놓여진 플레이어 말 정의: `standings` (`Pawn` 타입)
        - 어느 플레이어의 말인지 정의: `player`
        - 몇 마리가 겹쳐있는지 정의: `layers`
      - 플레이어별 말 대기실 정의: `beforeStart` (`{ 정수: 정수 }` 타입)
      - 플레이어별 도착한 말 수 정의: `finished` (`{ 정수: 정수 }` 타입)
    - UI 정의
      - 모달 유형 정의: `modalType` (`ModalType` 타입)
        - 인원 수 선택 모달
        - 게임 결과 모달
      - 모달 텍스트 콘텐츠 정의: `modalTextContent` (문자열 타입)
