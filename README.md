# ViteYutnori
Vite + React + 상태 관리 라이브러리(Jotai 또는 Zustand)로 만든 윷놀이 게임. (현재 앱 제작 중)

## 목적
- 윷놀이 실물을 들고 다닐 수가 없어 태블릿이나 PC를 통해 가족이나 친구끼리 할 수 있는 윷놀이 게임을 만들어보고자 함.
- 넷마블 윷놀이의 경우 확률적으로 "낙"이 발생할 수 있어, 불쾌감의 가능성이 있음.
- 그래서 "낙"이 없으며, 웹 브라우저를 가지고 있으면 실물이 없어도 즐길 수 있는 게임을 만들고 싶음.

## 게임 규칙
- 플레이 인원 수를 정한다. (2~4명)
- 플레이 인원 수가 정해지면 인원 수에 맞게 게임을 초기화한다.
- 3개의 일반 윷가락, 1개의 특수 윷가락, 총 4개의 윷가락을 던진다.
  - 도: 1개의 일반 윷가락만 펴져 있고, 나머지 세 윷가락은 엎어져 있을 때.
  - 개: 두 윷가락(일반/특수 무관)이 펴져 있을 때.
  - 걸: 세 윷가락(일반/특수 무관)이 펴져 있을 때.
  - 윷: 네 윷가락이 모두 펴져 있을 때.
    - 윷가락을 한 번 더 던질 수 있다.
  - 모: 네 윷가락이 모두 엎어져 있을 때.
    - 윷가락을 한 번 더 던질 수 있다.
  - 빽도: 1개의 특수 윷가락만 펴져 있고, 나머지 세 윷가락은 엎어져 있을 때.
    - 윷판에 놓여진 자기 말이 없으면 턴을 스킵한다.
- 이번 턴에서 더 이상 윷가락을 던질 수 없게 됐을 때, 윷가락을 던진 결과마다 움직일 말을 골라 이동시킨다.
  - 대기실에 있는 말을 이동시킬 때, 0번부터 첫번째 칸으로 시작하여 이동한다.
    - 예 1: 도로 대기실에 있는 말을 이동시킬 때 그 말을 0번째 칸에 멈춘다.
    - 예 2: 걸로 대기실에 있는 말을 이동시킬 때 그 말을 2번째 칸에 멈춘다.
  - 이미 윷판에 놓여진 말을 이동시킬 경우, `board-moves.png`의 표를 참고.
  - 참고로, 초기에 대기실에는 각 플레이어마다 4개의 말이 있다.
- 업기
  - 동일한 플레이어의 말과 같은 곳에 멈췄을 경우, 말을 포갠다.
    - 동일한 플레이어의 말을 지나쳤을 경우 포개지 않는다.
  - 포갠 말은 다른 플레이어의 말에 잡히거나 골인할 때까지 한 몸으로 움직이게 된다.
- 잡기
  - 다른 플레이어의 말과 같은 곳에 멈췄을 경우, 말을 잡아 대기실로 돌려보낸다.
    - 다른 플레이어의 말을 지나쳤을 경우 잡지 않는다.
    - 잡아놓은 다른 플레이어의 말이 포갠 상태였다면, 포갠 수만큼 대기실로 돌려보낸다. 또한, 대기실로 돌려보내진 말은 다시 따로따로 출발해야 한다.
  - 다른 플레이어의 말을 잡을 때마다, 윷가락을 던질 기회가 한 번 더 주어진다.
- 승리
  - 4개의 말을 모두 골인시키는 플레이어가 승리한다.
